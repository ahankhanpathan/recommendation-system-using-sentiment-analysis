# Hybrid Product Recommendation System with Sentiment Analysis & GNN

This repository contains a **hybrid product recommendation engine** that integrates **transformer-based embeddings**, **graph neural networks (GNNs)**, **aspect-based sentiment analysis**, and an **attention fusion model** to deliver personalized and explainable product recommendations.

## Features

- **Aspect-Based Sentiment Analysis** using LLMs (Groq LLaMA 3.0) to enrich product data with sentiment scores and aspect keywords.
- **Transformer embeddings** (Sentence-BERT / MiniLM) for rich semantic product representations.
- **Graph Neural Network (GNN)** encoding product relationships based on cosine similarity and category constraints.
- **Attention-based fusion model** combining text, graph, category, numerical, and aspect features into a single vector.
- **Streamlit UI** for interactive product search and recommendation.
- **Explainable recommendations** with natural language rationale generated by an LLM.
- **Comprehensive evaluation** metrics: Precision@k, Recall@k, F1@k, NDCG@k, and catalog coverage.

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure

Copy `config.yaml` and set:
- `data.input_file`: path to your product CSV
- `paths.model_path`: path to a saved model folder (for evaluate/recommend modes)
- `explainability.groq_api_key`: your Groq API key

### 3. Run sentiment analysis (optional pre-processing step)

```bash
python scripts/sentiment_batch.py \
  --csv_path data/raw/reviews.csv \
  --save_path data/processed/sentiment.csv \
  --model llama3-8b-8192
```

### 4. Train the model

```bash
python scripts/run_recommendation.py \
  --config config.yaml \
  --data data/processed/input.csv \
  --mode train
```

### 5. Evaluate

```bash
python scripts/run_recommendation.py \
  --config config.yaml \
  --data data/processed/input.csv \
  --mode evaluate
```

### 6. Generate recommendations (CLI)

```bash
python scripts/run_recommendation.py \
  --config config.yaml \
  --data data/processed/input.csv \
  --mode recommend
```

### 7. Launch the Streamlit app

```bash
streamlit run app/streamlit_app.py
```

Set the `MODEL_DIR` environment variable or update `config.yaml` (`paths.model_path`) to point to your trained model directory before launching.

## Data Format

The input CSV should contain these columns:

| Column | Description |
|---|---|
| `title` | Product title |
| `description` | Product description |
| `text` | Review text |
| `main_category` | Product category |
| `rating` | Numerical rating (e.g. 1–5) |
| `price` | Price |
| `sentiment` | `positive` / `neutral` / `negative` (from sentiment analysis) |
| `score` | Sentiment confidence score [0–1] |
| `aspects` | JSON list of aspect keywords |

## Architecture

```
Input CSV
  ↓
Text (title + description + review)
  → Sentence-BERT (384-dim)
Category → One-hot encoding
Numerical → [score, rating, price]
Aspects → Multi-label binary
  ↓
Graph building (k-NN cosine similarity, same-category constraint)
  → GNN (GCN / GAT) → 64-dim graph embeddings
  ↓
5 Projection layers → 128-dim each
  ↓
Attention Fusion (Q-K-V) → 128-dim fused vector
  ↓
Predictor MLP → Binary classification (positive / negative interaction)
```

## Evaluation Metrics

| Metric | Description |
|---|---|
| Precision@k | Fraction of top-k recommendations that are relevant |
| Recall@k | Fraction of relevant items found in top-k |
| NDCG@k | Ranking quality of the top-k list |
| Coverage | Fraction of catalog items ever recommended |
